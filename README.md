# Kufar Monitor Bot

Telegram-бот следит за новыми объявлениями на kufar.by и сразу присылает их с фото (листаются кнопками ◀️ ▶️), ценой, параметрами и описанием.

## Как пользоваться
1. `/start` → **➕ Новый мониторинг**
2. Пишешь запрос как в поиске Kufar (`квартира`, `iphone 13`…)
3. Выбираешь область → город (или «Вся область»)
4. Выбираешь валюту и диапазон цен (или свой: `200-800`)
5. Бот присылает самое свежее объявление для примера и дальше уведомляет о каждом новом.

**📋 Текущие мониторинги** — список с кнопками «Пауза / Включить / Удалить».

## Установка на сервер (Ubuntu/Debian)
```bash
curl -fsSL https://raw.githubusercontent.com/MatveyAndrosyukk/kufar/master/install.sh | BOT_TOKEN=<токен> bash
```
Скрипт ставит Docker (если его нет), клонирует репозиторий в `/opt/kufar-bot`, создаёт `.env` и запускает контейнер.

Обновить до последней версии: `bash /opt/kufar-bot/install.sh`
Логи: `cd /opt/kufar-bot && docker compose logs -f`

## Настройки (`/opt/kufar-bot/.env`)
| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `CHECK_INTERVAL` | пауза между проверками, сек (по умолчанию 60) |
| `ALLOWED_USERS` | Telegram ID через запятую, кому можно пользоваться ботом; пусто — всем |

После изменения: `docker compose up -d`.

## Устройство
- `app/kufar.py` — запросы к `api.kufar.by/search-api/v2/search/rendered-paginated`, фильтры, фото, описание
- `app/monitor.py` — фоновый цикл проверки новых объявлений
- `app/handlers.py` — меню и создание мониторинга
- `app/notify.py` — карточка объявления и листание фото
- SQLite в `./data/bot.db`

# Бот квартир (Kufar + Realt + Flatly)

Второй бот в этом же репозитории (`flats/`), запускается отдельным контейнером `flats-bot`.

| Что ищем | Источники |
|---|---|
| 🏠 Снять надолго | Kufar, Realt |
| 🛏 Посуточно | Realt, Flatly |
| 🔑 Купить | Kufar, Realt |

Выбор: тип → область → город → валюта и цена. Для городов Минской области Realt не поддерживается (только Kufar).
Токен второго бота — `FLATS_BOT_TOKEN` в `.env`.

## Деплой
Пуш в `master` → GitHub Actions заходит на сервер, обновляет оба бота и проверяет, что они подключились к Telegram, а все сайты отдают объявления.
